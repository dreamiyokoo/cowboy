# 開発・本番環境構成

システムの全体構成、各種サービス、環境変数、および接続ポート等の詳細についてまとめています。

---

## 1. システム構成・サービス一覧

Docker Compose (`docker-compose.yml`) を用いて、以下のコンポーネントが連携して動作しています。

| サービス名 | イメージ・ビルド情報 | 主な用途・特徴 |
| :--- | :--- | :--- |
| **frontend** | `frontend/Dockerfile` (Next.js) | ダッシュボード（フロントエンド画面）の提供。Basic認証対応。 |
| **api** | `api/Dockerfile` (FastAPI) | データ処理・ゲーム結果の保存・プレビュー配信用の REST API。 |
| **db** | `postgres:16-alpine` | ゲームデータ、マスターデータの格納。起動時に `db/init.sql` を適用。 |
| **redis** | `redis:7-alpine` | キャプチャプレビュー等のリアルタイム一時データのキャッシュ。 |
| **capture** | `capture/Dockerfile` (Python) | ADB経由での画像取得、OpenCV + OCR (Tesseract / EasyOCR) による画面解析。 |
| **cloudflared** | `cloudflare/cloudflared` | 外部から安全にアクセスできるようにするための Cloudflare Tunnel デーモン。 |

---

## 2. 稼働URLとポートマッピング

### 公開URL (本番・開発兼用)
* **URL:** [https://cowboy.dreami.jp/](https://cowboy.dreami.jp/)

### ローカルポートマップ
開発環境では、ホスト側から以下のポートで各サービスにアクセスできます。

* **フロントエンド:** `http://localhost:3000`
* **APIサーバー:** `http://localhost:8002` (コンテナ内ポート `8000`)
* **ADB サーバー (ホスト側):** `localhost:5037`
  * captureコンテナ内からは `host.docker.internal:5037` を通じて接続します。

## 3. 環境変数設定 (`.env`)

プロジェクトルートの `.env` ファイルで管理されている主な設定項目です。（`.env.example` がテンプレートとなっています）

```ini
# PostgreSQL 接続設定
POSTGRES_DB=cowboy
POSTGRES_USER=cowboy
POSTGRES_PASSWORD=changeme

# JWT トークン認証設定
JWT_SECRET=26acd0903038fdfff5c9f41f353f9a54834145d641849ce956a9816ff47719ce
JWT_EXPIRE_MINUTES=1440

# 初期データ投入 (Seed) 用管理者アカウント
SEED_USERNAME=goldship
SEED_PASSWORD=555555

# キャプチャ用アカウント (APIログイン用)
CAPTURE_USERNAME=admin
CAPTURE_PASSWORD=changeme

# Cloudflare Tunnel トークン
CLOUDFLARE_TUNNEL_TOKEN=eyJh... (略)

# フロントエンドのBasic認証設定 (任意)
FRONTEND_BASIC_AUTH_USER=
FRONTEND_BASIC_AUTH_PASS=
```

## 4. 各コンポーネントの役割と詳細

### フロントエンド (frontend)
* **フレームワーク:** Next.js (App Router)
* **ホスト名設定:** `0.0.0.0`
* **API参照先:** コンテナ間通信には `API_INTERNAL_URL=http://api:8000` を使用。
* **アクセス制御:** 必要に応じて `.env` に Basic 認証情報を記載することでアクセスを制限可能。

### APIサーバー (api)
* **フレームワーク:** FastAPI
* **データベース:** SQLAlchemy (非同期 `asyncpg`) を用いて PostgreSQL へ接続。
* **認証:** JWTトークンによるセキュアな認証。
* **キャッシュ:** Redis を用いてキャプチャ側から送信されるプレビュー用の画像・ステート情報を超高速にブラウザへ配信。

### データベース (db)
* **DBMS:** PostgreSQL 16
* **データの永続化:** Docker ボリューム `db_data` を使用。
* **初期化:** `db/init.sql` により必要なテーブルや初期スキーマがロードされます。

### Redis (redis)
* **データの永続化:** Docker ボリューム `redis_data` を使用。
* **役割:** `cowboy:capture:latest_preview` などのキーで最新キャプチャ状況を一時保持（生存時間: 600秒）。

### キャプチャ (capture)
* **言語/ライブラリ:** Python 3, OpenCV, Tesseract OCR, EasyOCR
* **接続方式:** Android デバイス（実機またはエミュレータ）に対して `adb exec-out screencap` で画面キャプチャを取得。
* **詳細設定:** `capture/config.yml` にて切り取り座標（クロップ範囲）、OCR拡大率、ベットポジションごとのオッズ等を設定します。

### Cloudflare Tunnel (cloudflared)
* **役割:** 踏み台や固定グローバルIPがなくても、Cloudflareを介してローカルホスト上のサービス（frontend / api）をセキュアに外部公開します。
